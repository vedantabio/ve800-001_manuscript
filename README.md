# VE800 Phase 1: microbiome, serum metabolite and cytokine analysis

R code for the analysis of VE800 colonization, gut microbiome, serum short-chain fatty acids (SCFA), bile acids (BA) and cytokines, and their relation to Week-8 clinical response (SD vs PD) and VE800 engraftment (HE vs LE).

This repository contains the **code** and the **processed data** (`Processed_data/`). Raw data are not included.

## Getting started

**Requirements:** R ≥ 4.2. Packages from CRAN, Bioconductor (`phyloseq`, `ComplexHeatmap`) and GitHub (`yingtools2`).

```r
# 1. Install packages (once)
source("install_packages.R")

# 2. Run everything
source("run_all.R")
```

Or run from a terminal in the project folder:

```bash
Rscript install_packages.R
Rscript run_all.R
```

Each analysis script writes to a folder with its own name: `scripts/04_serum_SCFA_analysis.R` → `Results/04_serum_SCFA_analysis/`.

You can also run any single script, e.g. `source("scripts/02_microbiome_diversity_and_taxa.R")`. All paths go through `here::here()`, so scripts work from any working directory inside the project.

**Without raw data** (anyone cloning this repo): `run_all.R` detects that `data/` is missing, skips script 01, and runs the analyses from `Processed_data/`.

**With raw data:** place the raw files in `data/` using the paths listed in `raw_files` at the top of `scripts/01_prepare_processed_data.R`, and that script regenerates all of `Processed_data/`. To rebuild only part of it, edit `steps` at the top of the script (e.g. `steps <- c("cytokines")`).

**Run-order dependency:** `07_colonization_predictors_ordinalNet.R` reads `VE800_Mean_RA_Subject.csv` produced by `03_VE800_colonization_summary.R`, so run 03 first.

## Scripts and outputs

Abbreviations: **SD / PD** = stable / progressive disease at Week 8; **HE / LE** = high / low VE800 engraftment (labelled **HC / LC** in the cytokine script); **LME** = linear mixed-effects model (`nlme::lme`, random intercept per subject); **BH** = Benjamini–Hochberg adjustment.

### 01_prepare_processed_data.R: build all processed data (raw data → `Processed_data/`)

One script with five parts that share the clinical metadata (Week-8 response, engraftment):

| Part | What it does | Output |
|---|---|---|
| A. Microbiome | One Codex species profiles → phyloseq object; fills missing ranks as `uncl_<Rank>_of_<parent>` | `phy_mic.rds`, `sample_metadata.csv` |
| B. Marker panel | VE800 marker panel joined to sample + clinical metadata | `VE303_abun.csv` |
| C. Serum metabolites | SCFA and BA results; BLOQ → LLOQ; visits recoded to study days | `SCFA_serum_melanoma.csv`, `BA_serum_melanoma.csv` |
| D. Cytokines | Cytokine panel (two-row header, 3 plates); below detection → plate LLOQ; log2 FC vs baseline; drops MFI ≥ 20 | `serum_cytokines_melanoma.csv` |
| E. Taxonomy | Copies the VE800 strain lineage reference file | `VE800_taxonomy.csv` |

Visit recoding used everywhere: `C1D1 → D1`, `C1D14 → D14`, `C2D1 → D30`, `C3D1 → D58`, `C4D1 → D86`.

### 07_colonization_predictors_ordinalNet.R: baseline features that predict VE800 colonization

For each VE800 strain, a penalised ordinal (cumulative-logit) elastic-net model (`ordinalNet`, 3-fold CV) predicts the strain's colonization class from **baseline** SCFA, bile acids, or microbiome (phylum to species, each fitted separately). Strains are fitted in parallel.

`Results/07_colonization_predictors_ordinalNet/`

| File | Figure / table |
|---|---|
| `Heatmap_Summary_Ordinal_net.pdf` | Selected baseline features per strain (blue = positive, red = negative association with colonization) |
| `<strain>/Barplot_<strain>_<dataset>.pdf` | Selected features by colonization class |
| `coeff_list.rds`, `perf_list.rds` | Non-zero coefficients and CV performance (misclassification, Brier) |
| `phy_glom_list.rds`, `baseline_data_list.rds` | Model inputs |
| `ordinalNet_parallel.log` | Messages from parallel workers |
